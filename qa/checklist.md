# 质检清单 · QA Checklist

> **怎么用：** 交付任何一条 AIGC 视频 prompt 之前，逐项勾选。**任一红项未通过，不交付。** 这是你的 skill 和网上普通 prompt 模板的本质区别——**人肉可验证**。

## 一、结构完整性（红项）

| # | 检查项 | 通过标准 | 失败示例 |
|---|---|---|---|
| 1 | 时长声明 | 有明确总时长 | "短视频" / 不写 |
| 2 | 画幅声明 | 有 `16:9` / `9:16` / `4:3` | 不写 |
| 3 | 时间轴分段 | 有 `[00:00-00:04]` 闭区间 | 只写总时长 |
| 4 | 分段总和 | 各段秒数相加 = 总时长 | 30s 只列到 24s |
| 5 | 固定块 | 有明确的角色/产品/品牌锁定 | 逐镜头重写外观 |
| 6 | 全局 Not Do | prompt 末尾有集中 Not Do | 无 / 埋在段中间 |
| 7 | 运镜精确 | 写具体术语 + 时间 + 机位 + 结束位置 | 只写 `cinematic movement` |
| 8 | 身份锁定 | 有 Token 声明 + 继承/不继承清单 | 无锁定 |

## 二、一致性（黄项 · 强烈建议）

| # | 检查项 | 通过标准 |
|---|---|---|
| 9 | Token 声明 | 每个角色/产品有短 Token，只在固定块写一次 |
| 10 | 继承清单 | 列出"永久不变"的核心外观 |
| 11 | 不继承清单 | 列出"会改变"的部分及改变时间点 |
| 12 | 数量钉死 | 写 `exactly ONE` / `only two` |
| 13 | 变装/变形前 | 核心外观保持不变 |
| 14 | 颜色锁定 | 写具体色名或 hex，不写 `deep blue` |
| 15 | 品牌/产品 | 特写避开 Logo 文字，改打材质 |
| 16 | 无分身 | 明确禁止 cloning / duplicates |

## 三、运镜精确度（黄项 · 强烈建议）

| # | 检查项 | 通过标准 |
|---|---|---|
| 17 | 机位明确 | 每个镜头有明确机位（Wide / Close-up / OTS / Overhead…） |
| 18 | 单机位/段 | 一秒只写一个机位 |
| 19 | 运动方向 | 写清方向（`pan left`, `push in`, `tilt up`） |
| 20 | 运动时长 | 写清持续秒数 |
| 21 | 结束位置 | 写清落点（`ending on face`, `ending on horizon`） |
| 22 | 速度/倍数 | 慢动作写减速倍数，FPV 写穿越物体 |

## 四、负面清单覆盖度（黄项 · 强烈建议）

| # | 检查项 | 通过标准 |
|---|---|---|
| 23 | 文字禁止 | 无 `no text`, `no letters` |
| 24 | 角色数量 | 无 `no extra characters` |
| 25 | 特征互换 | 无 `no attribute swap` |
| 26 | 文化礼仪 | 涉及宗教/文化场景时，有明确的 Not Do |
| 27 | 分身/克隆 | 无 `no cloning, duplicates` |
| 28 | 风格失守 | 有 `no [off-brand style]` |

## 五、交付前必做动作

```text
1. 重读 prompt 一遍，找"可想象但不可执行"的句子 → 改成"可执行"
   ❌ "cinematic camera movement" ✅ "Slow push-in over 4s, ending on face"
   ❌ "same person throughout" ✅ "exactly ONE woman, @Koru token, preserved"
   ❌ "keep it consistent" ✅ "No attribute swap, no cloning, exact color lock"

2. 检查时间轴是否闭合 → 各段秒数相加 = 总时长
   ❌ 15s = 4 + 3 + 4 + 3 + 4 = 18s（超了）
   ✅ 15s = 4 + 3 + 4 + 3 + 1 = 15s

3. 检查 Not Do 是否放在 prompt 末尾 → 是则通过，否则调整

4. 检查是否用了具体运镜术语 → 是则通过，否则去 movement-lexicon 查

5. 检查是否用了一致性锁三件套 → Token + 继承/不继承 + Not Do 齐全则通过
```

## 六、常见返工信号

| 症状 | 诊断 | 修复动作 |
|---|---|---|
| 视频 6 秒后开始漂 | 只写总时长不写分段 | 补时间轴闭区间 |
| 角色段间突变 | 逐镜头重写外观 | 改固定块 + Token |
| 多出第 3 只动物 | 数量没钉死 | 加 `exactly ONE` |
| 颜色漂移 | 没写色名 | 改具体 hex 或品牌色 |
| 运镜乱 | 用了 `cinematic` 这种废话 | 换具体术语 |
| 风格打架 | 堆了 5 个风格词 | 只留一个 |
| 时长不符 | 分段总和≠声明时长 | 调整段长 |
| 变形不自然 | 要求 `transformation` 无细节 | 逐件写出变化 |
